Мобильный анимационный баннер Buzzoola  

- баннер заниматет всё доступное пространство вьюпорта  
- 3 слайда, 1 слайд активен при открытии/перезагрузке страницы  
- при клике на кнопку открывается 2 слайд и запускается ccs-анимация поочередного появления шагов за 3 секунды  
- по окончании анимации шагов задержка в 2 секунды, после 2 слайд смахивается влево и появляется статичный 3 слайд на 3 сек, затем также смахивается влево
- 2 и 3 слайд циклично бесконечно сменяют друг друга  

Figma, HTML, CSS, JS
